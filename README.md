# Projects
=========================================Keylogger============================================
## ⚙️ Requirements
✅ You must have:
- Python 3 installed  
- Gmail account (with [App Passwords](https://myaccount.google.com/apppasswords) enabled)
-Install required Python package:
pip install pynput

## ✅ Step-by-Step Procedure (Single Script)
-Create a new file called: `keylogger.txt`  
-Paste the following complete code: Save as "Filename.py"
the Code is in *Keylogger.py file* 

## 🛠️ Step-by-Step Summary:

### 1. **Set Email Details**
Replace:
```python
EMAIL_ADDRESS = "your_email@gmail.com"
EMAIL_PASSWORD = "your_app_password_here"
TO_EMAIL = "recipient_email@gmail.com"
```
> ✅ Use [App Passwords](https://myaccount.google.com/apppasswords) from Gmail, not your actual password.

### 2. **Run the Script**
python keylogger.py

### 3. **Click Buttons**
- **Start Keylogger**: Begins logging keystrokes to `keystrokes.txt`.
- **Send Log via Email**: Sends the file to the email address.

## ⚠️ Safety & Ethics Reminder

✅ Run only on systems you **own** or **have written permission** to test.  
❌ Never deploy secretly. Unauthorized keylogging is **illegal** in most jurisdictions.
